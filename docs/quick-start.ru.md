# Быстрый старт

Нужен Node.js 22 или новее. Откройте терминал в папке этого набора инструментов:

```sh
npm ci --ignore-scripts
npm run theme -- init themes/ocean --name Ocean --repository https://github.com/YOUR-NAME/YOUR-THEMES
npm run theme -- preview themes/ocean --runtime .runtime/candidate --edition no-root
```

Сначала получите у сопровождающего локальный экспорт runtime и поместите всю
папку в `.runtime/candidate`. Официальный runtime пока не опубликован; подробности
в [runtime.md](runtime.md). Никакие адреса загрузки не подставляются автоматически.

Откройте в браузере адрес **http://127.0.0.1:8766/**, напечатанный в терминале.
Не закрывайте терминал. Редактируйте `themes/ocean/theme.css` и сохраняйте файл:
допустимые изменения применяются автоматически. При ошибке останется последний
рабочий вариант, а текст ошибки появится над интерфейсом Home. Остановка: **Ctrl+C**.
Занят порт? Добавьте `--port 8767`. Для Root используйте `--edition root`.

Несколько тем можно хранить в `themes/ocean/`, `themes/forest/`: у каждой свои
id, версия, лицензия и описание. Проверка: `npm run theme -- validate themes/ocean
--runtime .runtime/candidate` (введите одной строкой). Сборка и публикация описаны
в [publish.md](publish.md). Английская документация и контракт runtime определяют
точные ограничения. Просмотр в браузере не подтверждает работу на телевизоре.

## Посмотреть готовые темы

Чтобы увидеть настоящий интерактивный Home и переключать темы кнопками над ним:

```sh
npm run theme -- showcase examples --runtime .runtime/candidate --port 8877
```

Откройте **http://127.0.0.1:8877/** и нажимайте Classic, Alpine или Channel.
Classic выбрана при открытии: это исходное встроенное оформление Home.
Возврат к ней сбрасывает CSS и обои темы; явный выбор числа колонок сохраняется.
После выбора темы используйте мышь либо стрелки и Enter внутри экрана. При
переключении Home не перезагружается; порядок приложений и выбранное число
колонок сохраняются. Приложения и службы ТВ имитируются, подключения к ТВ нет.
Терминал должен оставаться открытым. Остановка — Ctrl+C. Это локальный showcase
кандидата; для него нужен подготовленный runtime, как и для preview одной темы.


Откройте `examples/index.html` двойным щелчком: это галерея сохранённых снимков
Home, входов и стандартных настроек. Node.js и runtime для неё не нужны.
В [каталоге примеров](../examples/README.md) есть Channel; Classic встроена в движок. Нужен свежий кандидат runtime с поддержкой раскладок;
ранний вариант с одной раскладкой их не поддерживает.

Для живого превью после подготовки runtime выполните:

```sh
npm run theme -- preview examples/terminal --runtime .runtime/candidate --edition no-root
```

Откройте напечатанный адрес. Весь экран ТВ автоматически уменьшается до размеров
окна ПК. Редактируйте `examples/terminal/theme.css`; это исходники Channel. Число колонок по умолчанию задаётся в `theme.json`; личная настройка
пользователя на ТВ имеет приоритет. Перед публикацией копии замените id, автора,
название и версию в манифесте на свои.

## Отправить локальную тему на ТВ по домашней сети

В preview или showcase выберите локальную тему и нажмите **Send to TV**.
Сначала на ТВ откройте **Настройки → Оформление → Получить с компьютера**.
Введите показанные на ТВ частный IPv4-адрес и шестизначный PIN в окно на
компьютере, затем нажмите **Send theme**. Оба устройства должны быть в одной
домашней сети. Компьютер отправляет тему исходящим подключением: разрешать
входящие подключения на компьютере не нужно. Classic встроена в Home, поэтому
для отправки выберите другую тему.

Сообщение **Sent** означает получение данных, а не установку темы. Завершите
проверку и установку на ТВ, затем выберите **Применить тему**. При ошибке снова
откройте приём на ТВ и проверьте текущий адрес и PIN. Гостевая Wi-Fi сеть и
изоляция клиентов могут блокировать связь. Не открывайте порт 8879 в интернет.
PIN не сохраняется и очищается при закрытии окна. После изменения CSS отправьте
тему ещё раз: команда соберёт новый снимок выбранной темы.

Без браузера:

```sh
npm run theme -- send themes/ocean --tv 192.168.1.20 --pin SIX_DIGITS --runtime .runtime/candidate
```

Замените адрес и PIN значениями с ТВ. На общем компьютере используйте окно
браузера, чтобы PIN не оставался в истории команд.

Для старых кандидатов, запрашивающих адрес **компьютера**, оставлен дополнительный
способ:

```sh
npm run theme -- share themes/ocean --runtime .runtime/candidate
```

Только этот старый способ запускает входящий сервер на компьютере (TCP 8879),
который может потребовать разрешение брандмауэра. Терминал должен оставаться
открытым; сессия истекает через 10 минут, Ctrl+C останавливает её. Кнопка
**Send to TV** этот сервер не запускает.
