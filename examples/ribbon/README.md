# Ribbon embedded UHD example

Next-release external author example, adapted from the main project’s packaged Ribbon. Original blue-violet procedural nebula on black space; 4096×2304 source, 20-second periodic camera drift, 3840×2160/FHD silent H.264 and JPEG fallback. See CREDITS.txt, LICENSE.txt, ARTWORK.md and wallpaper-preparation.json. The renderer script lives in the main project. This requires the paired video-wallpaper candidate runtime; browser preview is not physical-TV acceptance.
