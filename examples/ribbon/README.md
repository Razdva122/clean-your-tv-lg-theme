# Ribbon embedded UHD example

Next-release candidate author example, adapted from the main project theme source. The toolkit example has its own external identity so it can be built/sent through the normal author flow; the main project’s Ribbon remains a packaged built-in.

The theme includes a 3840×2160 JPEG fallback, silent UHD and FHD H.264 variants. Ribbon has a 20-second periodic editorial camera orbit over the real Webb observation. See CREDITS.txt, LICENSE.txt and wallpaper-preparation.json. Requires the matching video-wallpaper candidate runtime; no physical-TV acceptance is implied.
